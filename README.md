# Fixed Structure Research

**Trade the structure. Understand the market. Test both against evidence.**

**Public field guide:** https://titanicparker.github.io/crypto/

This repository is a small illustrated research publication about a fixed logarithmic market structure.

It has two independent investigations:

1. **Trade the structure** — can adjacent structural decisions be traded mechanically and survive realistic historical measurement?
2. **Understand the market** — does TOTAL, especially through the daily 100 SMA, reveal repeatable structural behaviour such as displacement, convergence, flattening and parallelism?

Both use the same invariant ladder. Neither is allowed to borrow proof from the other.
